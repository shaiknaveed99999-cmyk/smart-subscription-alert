# Launch Checklist

Manual steps remaining before Google Play Store submission.

- [ ] Replace `assets/icon.png`, `assets/splash.png`, and `assets/adaptive-icon.png` with Sage Green branded assets.
- [ ] Verify the UPI ID in the source code is correct.
- [ ] Host `docs/privacy-policy.html` on GitHub Pages or a free host.
- [ ] Run `npm run build:apk` to test on a physical Android device.
- [ ] Run `npm run build:aab` to generate the Play Store bundle.
- [ ] Create the app in Google Play Console and complete the Data Safety declarations.
